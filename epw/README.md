# Recommended EPW weather

The example simulation labels and predictions use:

`SWE_VG_Goteborg.City.AP.025120_TMYx.2011-2025.epw`

Download the matching `SWE_VG_Goteborg.City.AP.025120_TMYx.2011-2025.zip` from the [official Climate.OneBuilding Sweden directory](https://climate.onebuilding.org/WMO_Region_6_Europe/SWE_Sweden/index.html), extract the EPW, and place it in this folder:

```text
epw/SWE_VG_Goteborg.City.AP.025120_TMYx.2011-2025.epw
```

This is the Gothenburg City Airport TMYx file based on 2011–2025 source data, developed by Linda K. Lawrie and Drury B. Crawley (Climate.OneBuilding). The EPW is downloaded separately; it is not distributed with this repository.
